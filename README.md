# Todo Tree

Hierarchical todo list with nested subtasks, collapse/expand, and progress tracking.

## How to Use

**Step 1:** Open `index.html` in your browser.

**Step 2:** An onboarding tutorial appears on first visit. Click **Open Todo Tree** (or Skip).

**Step 3:** Type a task name and click **Add** (or press Enter). It appears as a top-level task.

**Step 4:** Hover over a task and click the **+ Sub** button to add a subtask underneath it.

**Step 5:** Click the circle next to any task to mark it as done.

**Step 6:** Click the arrow (&#9660;/&#9654;) to collapse or expand branches with subtasks.

**Step 7:** Progress (done/total) is shown automatically for parent tasks with children.

**Step 8:** Click the **x** button to delete a task and all its subtasks.

## Features
- Unlimited nesting depth (subtasks of subtasks)
- Collapse/expand branches
- Auto-calculated progress per parent
- Overall stats (total, done, percentage)
- Delete tasks with children
- LocalStorage persistence
